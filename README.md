# Power BI Sales Dashboard

## Project Overview

Developed an interactive Sales Dashboard using Microsoft Power BI to analyze sales performance, customer activity, product performance, and order trends.

The project demonstrates an end-to-end Power BI workflow, including data importing, cleaning, transformation, data modeling, DAX calculations, and report visualization.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling

## Dataset

The project uses two datasets:

- **Orders:** Sales transactions, products, quantities, dates, and related information.
- **Customers:** Customer information used for sales analysis and filtering.

## Project Workflow

1. **Data Import:** Imported Orders and Customers datasets into Power BI.
2. **Data Cleaning:** Handled missing values and standardized data types.
3. **Power Query Transformations:** Combined columns and formatted date fields.
4. **Data Modeling:** Created relationships between Orders and Customers.
5. **DAX Calculations:** Created measures and calculations for business KPIs.
6. **Visualization:** Developed an interactive dashboard with filters and charts.

## Dashboard Features

- Total Sales
- Total Customers
- Total Orders
- Sales Revenue by Product
- Quantity Sold by Product Category
- Country Filter
- Product Category Filter
- Interactive Order Date Range Slicer
